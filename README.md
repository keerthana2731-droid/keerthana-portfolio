## How to Get Your Live Public Link in 2 Minutes

### Method 1: Netlify Drop (Fastest — 30 Seconds, No setup needed)
1. Open [https://app.netlify.com/drop](https://app.netlify.com/drop) in your browser.
2. Drag and drop this folder (`keerthana-portfolio`) into the upload box.
3. You will immediately receive a live public URL (e.g., `https://keerthana-portfolio.netlify.app`).
4. Paste that link directly into the Ather Google Form!

### Method 2: GitHub Pages (Under your GitHub account)
1. Go to [https://github.com/new](https://github.com/new) and name the repo `portfolio`. Make sure it is set to **Public**.
2. In this folder, run:
   ```bash
   git remote add origin https://github.com/keerthana2731-droid/portfolio.git
   git branch -M main
   git push -u origin main
   ```
3. Go to your repo on GitHub: **Settings** -> **Pages** -> Select Branch: `main`, folder: `/ (root)` -> Click **Save**.
4. Your link will be: `https://keerthana2731-droid.github.io/portfolio/`
